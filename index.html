01. Apa itu Algoritma?

Algoritma adalah urutan langkah-langkah logis untuk menyelesaikan suatu masalah secara sistematis dan teratur.

Bayangkan komputer itu sangat pintar menghitung, tapi dia tidak tahu harus ngapain kalau tidak kita beri instruksi. Nah, instruksi urut itulah yang disebut Algoritma.

Contoh di Kehidupan Nyata: Memasak Nasi Goreng

  1. Mulai
  2. Nyalakan kompor dan letakkan wajan
  3. Tuang sedikit minyak goreng
  4. Masukkan bumbu dan telur, lalu tumis
  5. Masukkan nasi putih dan kecap
  6. Aduk rata hingga matang
  7. Sajikan di piring
  8. Selesai

02. 3 Struktur Dasar Algoritma

Sequential (Runtunan)

Langkah dijalankan satu per satu dari atas ke bawah. Tidak ada yang dilewati.

1. Buka browser
2. Ketik 'google.com'
3. Tekan Enter

Conditional (Percabangan)

Memiliki syarat. Jika syarat terpenuhi (True), lakukan A. Jika tidak (False), lakukan B.

JIKA wifi tersambung MAKA
  Bisa buka web
JIKA TIDAK
  Tampil Dinosaurus Offline

Looping (Perulangan)

Menjalankan langkah yang sama berkali-kali sampai batas tertentu tercapai.

ULANGI 4 kali:
  Kirim paket Ping ke router
  Tunggu balasan

03. Apa itu Pseudocode?

Pseudocode (Kode Semu) adalah cara penulisan algoritma yang menyerupai bahasa pemrograman, namun menggunakan bahasa manusia (Inggris/Indonesia) sehingga mudah dibaca. Ini adalah jembatan sebelum kita benar-benar menulis kode dalam bahasa Python, C++, atau PHP.

Kata Kunci Umum Pseudocode

Kata Kunci Fungsi
START / END Memulai dan mengakhiri program
READ / INPUT Menerima data masukan dari user
PRINT / WRITE Menampilkan hasil ke layar
IF ... THEN ... ELSE Struktur kondisi / percabangan
FOR / WHILE Struktur perulangan (Looping)

Contoh Pseudocode Menghitung Luas

START
    INPUT panjang
    INPUT lebar
    
    luas = panjang * lebar
    
    PRINT luas
END
